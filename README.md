## 📖 О проекте

**LinguaOCR** — это локальное веб-приложение для изучения языков, которое превращает фотографии ваших конспектов и текстов в интерактивные карточки для запоминания.

### 🎯 Для кого?

- **Изучающие китайский язык** — распознавание иероглифов с автоматическим добавлением пиньиня
- **Изучающие английский язык** — распознавание английских слов с автоматическим переводом на русский
- **Изучающие русский язык** — распознавание русских слов с автоматическим переводом на английский
- **Студенты языковых курсов** — быстрая оцифровка письменных конспектов 
- **Преподаватели** — создание учебных материалов из распечаток
- **Билингвы** - те, кому важно учить несколько языков в одном месте

### ✨ Ключевые возможности

| Функция | Описание |
|---------|----------|
| 📸 **OCR распознавание** | Загрузите фото конспекта — AI извлечёт все слова |
| 🗂️ **Мультиязычность** | Китайский, английский, русский |
| 🃏 **Флеш-карточки** | Автоматическое создание карточек с переводом |
| 🔄 **Режимы повторения** | Слово→Перевод или Перевод→Слово |
| 📊 **Статистика** | Счётчик правильных/неправильных ответов, прогресс-бар |
| ✍️ **Ручной ввод** | Добавляйте слова вручную, если AI не справился |
| 📥 **Импорт/экспорт** | Загрузка готовых колод в формате Anki |
| 💾 **Локальное хранение** | Ваши колоды сохраняются в JSON-файлы на вашем компьютере |
| 🔒 **Конфиденциальность** | Никаких серверов — всё работает локально |

## 🧠 Почему всё работает локально?

> *(У автора не было спонсоров на аренду сервера или платное API)*

Вместо этого я использовала:

- **Ollama** — локальный запуск LLM на вашем GPU
- **Qwen/LLaVA** — открытые мультимодальные модели
- **Flask** — лёгкий веб-сервер
- **jieba / NLTK / pymorphy2** — локальная токенизация

Это означает:
- ✅ **Бесплатно** — никаких подписок или платежей
- ✅ **Приватно** — ваши конспекты не уходят в облако
- ✅ **Офлайн** — работа без интернета после установки

## ⚙️ Принцип работы

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  📸 Фото    │────▶│  🦙 Ollama  │────▶│  ✂️ jieba   │────▶│  🃏 Карточки │
│  конспекта  │     │  (OCR)      │     │ (токенизация)│     │  с переводом │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
```

### 1. **OCR (распознавание текста)**
- Вы загружаете фото конспекта
- Ollama с мультимодальной моделью (Qwen) извлекает весь текст
- Модель видит изображение и выводит китайские/английские/русские символы

### 2. **Токенизация (разбиение на слова)**
- **Китайский** — jieba (профессиональная библиотека сегментации)
- **Английский** — NLTK + фильтрация стоп-слов
- **Русский** — NLTK + pymorphy2 (лемматизация)

### 3. **Перевод**
- Google Translate API (бесплатный, через `deep-translator`)
- Для китайского дополнительно добавляется пиньинь через `pypinyin`

### 4. **Хранение**
- Все колоды сохраняются в `data/chinese.json`, `data/english.json`, `data/russian.json`
- Простой JSON-формат — можно редактировать в любом текстовом редакторе

## 🚀 Установка и запуск

### 📦 Требования

| Компонент | Минимальные требования |
|-----------|----------------------|
| **Python** | 3.10+ |
| **Видеокарта** | NVIDIA RTX (рекомендуется) или CPU |
| **RAM** | 8+ GB |
| **Диск** | 10+ GB свободного места |
| **OS** | Windows / Linux / macOS |

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/1111111111666/LinguaOCR
cd LinguaOCR
```

### Шаг 2: Установка Python-зависимостей

```bash
pip install -r requirements.txt
python -c "import nltk; nltk.download('punkt'); nltk.download('stopwords')"
```

### Шаг 3: Установка Ollama и модели

**Windows / Linux / macOS:**

```bash
# Скачайте Ollama с официального сайта
curl -fsSL https://ollama.com/install.sh | sh   # Linux
# или скачайте установщик с https://ollama.com/download

# Запустите Ollama сервер (в отдельном окне терминала)
ollama serve

# Установите мультимодальную модель (выберите одну)
ollama pull qwen2-vl:7b        # Рекомендуется для китайского
# или
ollama pull llava:7b           # Универсальная
# или
ollama pull bakllava:7b        # Хороша для азиатских языков
```

### Шаг 4: Настройка модели в приложении

Откройте `app.py` и убедитесь, что модель указана правильно:

```python
AI_MODEL = 'qwen2-vl:7b'  # Замените на установленную модель
```

### Шаг 5: Запуск приложения

```bash
python app.py
```

Откройте браузер и перейдите по адресу: **http://localhost:5000**

## 🎮 Как пользоваться

### 📸 Распознавание с фото

1. Выберите язык (Китайский/Английский/Русский) в верхней панели
2. Перетащите фото конспекта в область загрузки (или нажмите Ctrl+V)
3. Дождитесь распознавания (10-60 секунд)
4. Нажмите **➕ Добавить** на нужных словах

### ✍️ Ручной ввод

1. Перейдите на вкладку **Ручной ввод**
2. Введите слово в поле
3. Нажмите **Добавить** — перевод подставится автоматически

### 📚 Повторение

1. Перейдите на вкладку **Повторение**
2. Нажмите **Начать повторение**
3. Кликните по карточке, чтобы увидеть перевод
4. Оцените себя: **Знаю** или **Забыл**

### 📥 Импорт колод

```text
Формат: слово;перевод (каждая строка)
Пример:
你;ты
好;хорошо
谢谢;спасибо
```

## ❓ Часто задаваемые вопросы

### Почему не распознаётся текст?

1. **Плохой почерк** — AI лучше работает с печатными текстами
2. **Ollama не запущен** — выполните `ollama serve` в отдельном терминале
3. **Не та модель** — убедитесь, что установлена мультимодальная модель (`qwen2-vl:7b`)
4. **Слишком долго** — распознавание может занимать 10-60 секунд

### Могу ли я добавить свой язык?

Да! Добавьте новый язык в словарь `LANGUAGES` в `app.py` и создайте соответствующий JSON-файл в папке `data/`.

### Как экспортировать колоду в Anki?

1. Перейдите на вкладку **Импорт/Экспорт**
2. Нажмите **Экспортировать колоду**
3. Скопируйте содержимое и сохраните в файл
4. Импортируйте в Anki (формат: `слово;перевод`)
